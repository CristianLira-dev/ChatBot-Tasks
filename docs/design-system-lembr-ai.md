# Design System — Lembraí

Este documento consolida o Design System `Appwrite Dark Developer` fornecido para o produto **Lembraí**. Ele é a referência única para novas telas e componentes.

## Identidade

O nome oficial do produto é **Lembraí**. Não usar placeholders de marca, nomes anteriores ou qualquer outro nome de produto em telas, mensagens, metadados ou componentes.

## Tokens visuais

| Categoria | Tokens oficiais |
|---|---|
| Superfícies | `#19191c` base, `#202023` elevada, `#232325` sutil |
| Ação e destaque | `#fd356e` pink da marca, `#85dbd8` mint secundário |
| Texto | `#e4e4e7` primário, `#acacaf` secundário, `#57575c` terciário, `#ffffff` sobre pink |
| Bordas | `#2c2c30` em dark, `#e4e4e7` em light |
| Tipografia de títulos | Aeonik Pro; títulos principais devem usar peso Bold quando forem headings de produto |
| Tipografia de interface | Inter, pesos 400, 500 e 700 |
| Tipografia técnica | Fira Code, pesos 400 e 500 |
| Raio | 4px, 6px, 8px, 12px, 14px, 16px, 32px e pill de 50px |
| Espaçamento | Grade base de 8px, com escala 4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80 e 128px |

## Princípios de aplicação

A interface deve permanecer dark-first, com contraste mínimo WCAG AA para texto normal, pink reservado à ação primária e destaque de marca, mint para estados positivos e links secundários, bordas discretas e geometria arredondada consistente. Os títulos de páginas, seções, cards de destaque, modais e headings devem usar **Bold**; textos corridos, labels e metadados devem preservar os pesos de interface definidos sem aplicar negrito indiscriminadamente.

Todos os componentes compartilhados devem usar estes tokens, inclusive header, sidebar, navegação, inputs, cards, tabelas, badges, botões, modais, dropdowns, estados de foco, hover, disabled, vazio, carregamento e erro. O painel, autenticação e landing devem parecer partes do mesmo produto.
